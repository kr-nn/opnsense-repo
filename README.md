# os-unboundviews pkg repository

Static FreeBSD pkg repository for private/community distribution of
`os-unboundviews` on OPNsense.

This repository is intentionally narrow. It contains only private OPNsense
plugin packages, not FreeBSD base packages or OPNsense core replacements.

## Current Target

- OPNsense: 26.7
- Package ABI: `FreeBSD:15:amd64`
- pkg: 2.3.1
- Initial package: `os-unboundviews-1.0`

The publishable tree is:

    public/

The initial repository root is:

    public/FreeBSD:15:amd64/26.7/latest/

The client repository URL should point at that directory, for example:

    https://REPLACE-ME.example/opnsense/${ABI}/26.7/latest

## Signing

Repository metadata is generated by `pkg repo` and signed with a dedicated RSA
repository key.

Secret:

    private/unboundviews-repo.key

Safe to distribute:

    client/unboundviews-repo.pub
    client/UnboundViews.conf.sample
    public/

Do not commit or publish `private/`.

## Regenerate Metadata

Run on a FreeBSD/OPNsense host with `pkg` available:

    ./scripts/update-repo.sh

To add a package and regenerate metadata:

    ./scripts/update-repo.sh /path/to/os-example-1.0.pkg

Defaults may be overridden:

    ABI=FreeBSD:15:amd64 SERIES=26.7 FLAVOUR=latest ./scripts/update-repo.sh

## Release Layout

Use one repository root per OPNsense series and FreeBSD ABI:

    public/FreeBSD:15:amd64/26.7/latest/
    public/FreeBSD:15:amd64/26.7/testing/
    public/FreeBSD:15:amd64/27.1/latest/

The package annotations generated by the OPNsense plugin framework include
`product_abi` and `product_arch`. The repository path should still separate
builds by pkg ABI and OPNsense series so a firewall does not see packages built
for a different base.

## Client Repo

Install the public key and a repo config based on:

    client/unboundviews-repo.pub
    client/UnboundViews.conf.sample

See `BOOTSTRAP.md`.
